# About — image dimensions

Images are displayed inside the collage with `object-fit: cover` (cropped to fill). Export as **WebP**, 2× retina
density.

| File           | Collage slot        | Recommended size  |
|----------------|---------------------|-------------------|
| `about-1.webp` | 47% wide × 43% tall | **800 × 620 px**  |
| `about-2.webp` | 52% wide × 40% tall | **900 × 580 px**  |
| `about-3.webp` | 77% wide × 50% tall | **1100 × 720 px** |

Keep the subject centred — the crop shifts slightly depending on the viewport.
